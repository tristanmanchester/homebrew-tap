# Tristanmanchester Tap

## How do I install these formulae?

`brew install tristanmanchester/tap/<formula>`

Or `brew tap tristanmanchester/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "tristanmanchester/tap"
brew "<formula>"
```

## Rheo

Install the macOS Space switcher and its CLI:

```sh
brew install --cask tristanmanchester/tap/rheo
open -a Rheo
```

Enable Rheo in **System Settings > Privacy & Security > Accessibility** on first launch.
See [Rheo](https://github.com/tristanmanchester/rheo) for usage and source code.
